## 🎬 VISUALIZATION PRINCIPLES

Each visualization is created as part of the same continuous project.

**The core principles:**

- Follow the Book of Enoch sequentially
- Preserve chapter and verse references
- Keep the meaning of the source text central
- Build cinematic visual interpretations of ancient imagery
- Maintain continuity across the complete journey
- Clearly distinguish visual interpretation from the ancient text itself

---

## 📜 PRIMARY TEXT

The visualization project primarily follows the **R. H. Charles English translation of 1 Enoch (1917)**.

Chapter and verse references are preserved throughout the project so viewers can identify the passage behind each visualization.

Visual elements may interpret imagery cinematically when the ancient text does not provide a complete physical description.
